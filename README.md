# School Timetable Management System

A full-stack web application designed to create, manage, and view school schedules effortlessly. Built with a **Django** backend, a **React** frontend, and styled with clean, responsive **CSS**.

## ✨ Features
- **Interactive Timetable View:** Easily view daily and weekly class schedules with a clean, user-friendly layout.
- **Schedule Management:** Add, update, and organize subjects, teachers, classrooms, and time slots.
- **Responsive Design:** Custom CSS styling that works smoothly across desktop and mobile screens.
- **Lightweight Database:** Powered by SQLite for fast, zero-configuration data storage.

## 🛠️ Tech Stack
- **Frontend:** React, CSS3
- **Backend:** Python, Django (Django REST Framework)
- **Database:** SQLite

## 🚀 How to Run in GitHub Codespaces

### 1. Start the Backend (Django)
Open a terminal in your Codespace and run:
```bash
# Navigate to your backend directory (if in a subfolder)
# cd backend

# Apply database migrations
python manage.py migrate

# Start the Django server
python manage.py runserver
```

### 2. Start the Frontend (React)
Open a second terminal in your Codespace and run:
```bash
# Navigate to your frontend directory (if in a subfolder)
# cd frontend

# Install dependencies (first time only)
npm install

# Start the React development server
npm start
```

### 3. Open in Browser
- Check the **Ports** tab in your Codespace terminal panel.
- Click the **globe icon (Open in Browser)** next to your active frontend port to view the live app.
